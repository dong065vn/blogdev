# /ui - UI/UX Polish

## Cách dùng
```
/ui [component/page]    # Làm đẹp component cụ thể
/ui audit               # Audit toàn bộ UI
```

## Quy trình

### Step 1: UI Audit
1. Kiểm tra hiện trạng:
   - Consistency (fonts, colors, spacing)
   - Responsive (mobile/tablet/desktop)
   - Accessibility (contrast, labels, focus)
   - Performance (load time, animations)

### Step 2: Design System
2. Áp dụng design tokens:
   - Colors: primary, secondary, accent, neutral
   - Typography: heading, body, caption
   - Spacing: 4px grid system
   - Border radius, shadows

### Step 3: Polish
3. Visual improvements:
   - Modern typography (Inter, Roboto, Outfit)
   - Smooth gradients thay vì flat colors
   - Micro-animations (hover, transition, loading)
   - Glassmorphism, subtle shadows
4. Interaction design:
   - Hover effects (scale, color change)
   - Loading states (skeleton, spinner)
   - Error states (inline messages)
   - Empty states (helpful illustrations)
5. Accessibility (WCAG 2.1):
   - Color contrast ≥ 4.5:1
   - Focus indicators rõ ràng
   - Alt text cho images
   - Keyboard navigation

### Step 4: Responsive
6. Mobile-first approach
7. Breakpoints: 640px (sm), 768px (md), 1024px (lg)
8. Test trên multiple viewports

- Design tokens/variables
